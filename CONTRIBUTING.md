# Contributing

Contributions that improve documentation, data validation, or independent
analysis of the released datasets are welcome.

Before proposing a change:

1. keep original simulation outputs numerically unchanged;
2. place derived data or figures in a clearly named new directory;
3. document the script and command used to generate derived artifacts;
4. run `python scripts/validate_repository.py`; and
5. explain any discrepancy with the published reports.

Do not commit proprietary PDK files, foundry models, Cadence installation data,
credentials, or other material that cannot be redistributed.
